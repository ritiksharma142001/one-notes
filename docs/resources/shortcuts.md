On macOS use <kbd>Cmd</kbd> for <kbd>Ctrl</kbd> and <kbd>Option</kbd> for <kbd>Alt</kbd> unless noted.

## VS Code

| Action | Shortcut |
|---|---|
| Command palette | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> |
| Go to file | <kbd>Ctrl</kbd>+<kbd>P</kbd> |
| Go to symbol in file | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> |
| Go to definition / peek | <kbd>F12</kbd> / <kbd>Alt</kbd>+<kbd>F12</kbd> |
| Find references | <kbd>Shift</kbd>+<kbd>F12</kbd> |
| Rename symbol | <kbd>F2</kbd> |
| Quick fix | <kbd>Ctrl</kbd>+<kbd>.</kbd> |
| Search in all files | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| Multi-cursor: next match | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| Multi-cursor: all matches | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> |
| Cursor above / below | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> |
| Move line up / down | <kbd>Alt</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> |
| Copy line up / down | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> |
| Delete line | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> |
| Toggle comment | <kbd>Ctrl</kbd>+<kbd>/</kbd> |
| Format document | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> |
| Toggle terminal | <kbd>Ctrl</kbd>+<kbd>`</kbd> |
| Toggle sidebar | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Split editor | <kbd>Ctrl</kbd>+<kbd>\\</kbd> |
| Back / forward | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>-</kbd> |

## IntelliJ IDEA

| Action | Shortcut |
|---|---|
| Search everywhere | <kbd>Shift</kbd> <kbd>Shift</kbd> |
| Find action | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> |
| Go to class / file | <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> |
| Recent files | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Go to declaration / implementation | <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> |
| Find usages | <kbd>Alt</kbd>+<kbd>F7</kbd> |
| Show intention actions | <kbd>Alt</kbd>+<kbd>Enter</kbd> |
| Generate (constructor, getters…) | <kbd>Alt</kbd>+<kbd>Insert</kbd> |
| Rename | <kbd>Shift</kbd>+<kbd>F6</kbd> |
| Refactor this | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> |
| Extract variable / method | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> / <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd> |
| Reformat code | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd> |
| Optimise imports | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>O</kbd> |
| Duplicate line | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| Expand selection | <kbd>Ctrl</kbd>+<kbd>W</kbd> |
| Run / debug | <kbd>Shift</kbd>+<kbd>F10</kbd> / <kbd>Shift</kbd>+<kbd>F9</kbd> |
| Step over / into / resume | <kbd>F8</kbd> / <kbd>F7</kbd> / <kbd>F9</kbd> |
| Evaluate expression | <kbd>Alt</kbd>+<kbd>F8</kbd> |

Live templates: type `psvm`, `sout`, `fori`, `iter` and press <kbd>Tab</kbd>.

## Chrome DevTools

| Action | Shortcut |
|---|---|
| Open DevTools / inspect element | <kbd>F12</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> |
| Command menu | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> (inside DevTools) |
| Device toolbar (mobile view) | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> |
| Hard reload | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> |
| Search all sources | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| Console: last inspected element | `$0` |
| Console: copy a value | `copy(obj)` |

## Ubuntu / GNOME

| Action | Shortcut |
|---|---|
| Open terminal | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> |
| Activities / app search | <kbd>Super</kbd> |
| Switch apps / windows of the same app | <kbd>Alt</kbd>+<kbd>Tab</kbd> / <kbd>Alt</kbd>+<kbd>`</kbd> |
| Snap window left / right | <kbd>Super</kbd>+<kbd>←</kbd>/<kbd>→</kbd> |
| Lock screen | <kbd>Super</kbd>+<kbd>L</kbd> |
| Screenshot tool | <kbd>Print</kbd> |
| Terminal copy / paste | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> / <kbd>V</kbd> |

Terminal line editing (Bash): see [Terminal shortcuts](../shell/keyboard-shortcuts.md).
