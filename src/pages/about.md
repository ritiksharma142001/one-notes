# About One Notes

I'm [Ritik Sharma](https://eritik.vercel.app/), a software developer in Bengaluru working with Java, Spring Boot and React. I started this site to keep everything I learn in **one place** — and to make revision before interviews fast.

## How the notes are written

- **Cheat-sheet first.** Short explanations, runnable code and comparison tables — no filler.
- **Interview-ready.** Most pages end with *interview quick answers* you can say out loud.
- **Searchable offline-style.** Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>/</kbd>) to search every page; nothing is tracked.
- **Always improving.** Every page has an *Edit this page* link — fixes and suggestions are welcome as pull requests.

## Topics

Core Java · Advanced Java (JDBC, Servlets, Spring Boot, JPA) · JavaScript · React · HTML, CSS & Tailwind · Node.js & Express · SQL, PostgreSQL & MongoDB · Git & GitHub · Linux & Shell · System design · Operating systems, DBMS & networks · Interview questions.
